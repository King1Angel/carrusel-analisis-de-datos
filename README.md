Aplicación web interactiva tipo portafolio/CV orientada al mercado de **Ciencia de Datos, Machine Learning y Análisis de Datos (ECBD - Extracción de Conocimiento en Bases de Datos)** por **Miguel Ángel Peña Pech**.

Cada módulo presenta la evidencia técnica original con **3 carruseles simultáneos que rotan aleatoriamente cada 30 segundos** entre las páginas del documento PDF correspondiente, integrando botones de acceso directo a Google Drive y un visor modal ampliado.

## 🛠️ Características de la Aplicación

- **3 Carruseles en Paralelo por Actividad:** Visualización sincronizada de diferentes páginas del mismo informe técnico.
- **Motor de Rotación Aleatoria cada 30 segundos:** Temporizador visual y barra de progreso fluida en tiempo real.
- **Controles Interactivos:** Botón de Pausa / Reanudación, rotación forzada y flechas de navegación página a página.
- **Renderizado Nativo con PDF.js:** Renderizado nítido de los documentos PDF en elementos `<canvas>` con fallback automático.
- **Visor Modal en Alta Definición:** Inspección detallada con zoom al dar clic sobre cualquier página.
- **Filtros por Categoría:** Filtrado instantáneo entre *Machine Learning*, *Python & EDA*, *SQL & ETL* y *Metodología*.
- **Diseño Glassmorphism Responsive:** Estilo técnico moderno optimizado para desktop, tablets y teléfonos móviles.
